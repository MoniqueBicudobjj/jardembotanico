Jardim Botânico - Flores que abraçam

O Jardim Botânico é um site elegante e responsivo para uma floricultura, focado em transmitir aconchego e conexão com a natureza. Desenvolvido para demonstrar a integração entre design floral, navegação intuitiva e páginas estáticas com HTML5 e CSS3.

Funcionalidades

- Barra lateral (Sidebar) com navegação entre 5 páginas principais
- Página Inicial com vitrine de produtos (Maver, Caléola, Mimen) e depoimento de cliente
- Página Floricultura com exibição das espécies cultivadas
- Página Vendas com cards de ofertas e produtos
- Página Sobre Nós com história e valores da empresa
- Página Contato com formulário e informações de contato
- Botões de compra com feedback interativo (alertas simulados)
- Design responsivo adaptado para tablets e smartphones
- Estilo visual suave com gradientes, ícones florais e tipografia acolhedora

Tecnologias Utilizadas

O projeto utiliza tecnologias modernas e semânticas no desenvolvimento front-end:

Tecnologia: HTML5 - Descrição: Estruturação semântica das páginas da aplicação

Tecnologia: CSS3 - Descrição: Estilização avançada com flexbox, grid, gradientes e animações suaves

Tecnologia: JavaScript - Descrição: Interatividade para navegação ativa e feedback dos botões

Tecnologia: Google Fonts - Descrição: Tipografias Inter e Playfair Display para uma experiência visual acolhedora

Tecnologia: Git - Descrição: Controle de versionamento do projeto

Estrutura do Projeto

- index.html - Página inicial (produtos e depoimento)
- floricultura.html - Página com as espécies de flores
- vendas.html - Página com ofertas e produtos
- sobre.html - Página institucional (história e valores)
- contato.html - Página com formulário de contato
- inicio.css - Estilos globais do projeto (todas as páginas)
- README.md - Documentação do projeto

Como Rodar o Projeto

Passo 1: Clone este repositório ou baixe todos os arquivos
git clone https://github.com/seu-usuario/jardim-botanico.git

Passo 2: Navegue até a pasta do projeto
cd jardim-botanico

Passo 3: Abra o arquivo index.html no seu navegador preferido
Você pode clicar duas vezes no arquivo ou usar a extensão Live Server do VS Code para melhor experiência

Passo 4: Navegue pelas páginas clicando nos botões da barra lateral

Importante: Todos os arquivos devem estar na mesma pasta para os links funcionarem corretamente.

Desafio de Auditoria (Atividade Acadêmica)

Este repositório faz parte de uma dinâmica de análise crítica de código. Embora o sistema pareça funcional e visualmente agradável, ele contém pontos que podem ser melhorados ou corrigidos propositalmente.

Seu objetivo como auditor é:

- Encontrar falhas na estrutura HTML (semântica, acessibilidade)
- Identificar bugs de renderização ou responsividade
- Apontar melhorias na Experiência do Usuário (UX)
- Sugerir otimizações de performance e boas práticas CSS
- Abrir uma Issue detalhando cada ponto encontrado

Possíveis áreas de análise:

HTML: Tags semânticas (header, main, section), atributos alt em imagens, hierarquia de títulos

CSS: Responsividade em diferentes resoluções, uso de unidades relativas, possíveis conflitos de estilo

UX: Feedback visual nos botões, tempo de carregamento, navegação clara e consistente

JavaScript: Tratamento de erros, eventos duplicados, performance do DOM
